対応TLDと料金

すべて税込・1年あたり。初年度が安いTLDほど、2年目からの更新料が上がります。

復旧料（有効期限切れ後の取り戻し）は ¥3,300 〜 ¥6,600。.dev / .app はHSTSプリロード済みのため常時HTTPS化が必須です。レジストリは Kitaqsign（.com / .net / .org / .info）と Kitaqnic（その他18種）の2社です。

決めた三つのこと

1

TLDを先に選ばせない

対応する22のTLDすべてに毎回問い合わせます。ひとつずつ試し直す必要はありません。

2

取れる候補だけを提案

希望がすべて埋まっていたときだけ、その場で空きを再確認できた候補を出します。

3

分からないと書く

接続できなかったTLDは空きとも使用中とも表示しません。◯ / ✕ / ？ を記号と文字で区別します。
