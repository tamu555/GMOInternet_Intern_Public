対応している22のTLDと料金

すべて税込・1年あたり。初年度が安いTLDほど2年目からの更新料が上がるので、更新料も必ず並べて表示しています。

復旧料（有効期限切れ後の取り戻し）は ¥3,300 〜 ¥6,600。.dev / .app はHSTSプリロード済みのため常時HTTPS化が必須です。レジストリは Kitaqsign（.com / .net / .org / .info）と Kitaqnic（その他18種）の2社です。

はじめてでも、つまずかないように

1

TLDは選ばなくていい

名前だけ入れれば、対応する22のTLDすべてに問い合わせます。「.com がだめなら次は .net」と試し直す必要はありません。

2

だめなときは代わりを出す

希望がすべて埋まっていたときだけ、似た候補を出します。しかも、その場で空きを確認できたものだけを表示します。

3

分からないときは、そう書く

レジストリに繋がらなかったTLDは、空きとも使用中とも書きません。◯ / ✕ / ？ を記号と文字の両方で区別します。
