初年度の安さだけで選ばないでください

¥98 のTLDは、2年目から ¥1,680 になります。初年度と更新料を必ず同じ大きさで並べて表示します。すべて税込・1年あたりです。

復旧料（有効期限切れ後の取り戻し）は ¥3,300 〜 ¥6,600。.dev / .app はHSTSプリロード済みのため常時HTTPS化が必須です。レジストリは Kitaqsign（.com / .net / .org / .info）と Kitaqnic（その他18種）の2社です。

TLDを先に選ばせない

対応する22のTLDすべてに毎回問い合わせます。「.com がだめなら次は .net」と試し直す必要はありません。

取れる候補だけを提案

希望がすべて埋まっていたときだけ似た候補を出します。その場で空き状況を再確認できたものに限って表示します。

分からなかったと書く

レジストリに接続できなかったTLDは、空きとも使用中とも表示しません。◯ / ✕ / ？ を記号と文字で区別します。
