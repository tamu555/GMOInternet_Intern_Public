第1章 ドメインを取る前に、いちど確かめる

ほしい名前がまだ空いているか、
ここで確かめられます。

ドメイン名は、早い者勝ちです。同じ名前をふたりが持つことはできません。だからまず、その名前が残っているかを見ます。手順はひとつだけです。

やってみましょう

ログイン不要／10秒ほどで終わります

TLD（.com など）は含めず入力してください。全角文字は自動的に半角へ変換されます。

  • 22のTLDへまとめて問い合わせます
  • 2つの料金（初年度・更新）を必ず並記します
  • 0円、会員登録もカード登録も不要です

対応している22のTLDと料金

すべて税込・1年あたりの金額です。初年度が安いTLDほど、2年目からの更新料は高くなります。見るときは、必ず右となりの更新料まで目を通してください。

復旧料（有効期限切れ後の取り戻し）は ¥3,300 〜 ¥6,600。.dev / .app はHSTSプリロード済みのため常時HTTPS化が必須です。レジストリは Kitaqsign（.com / .net / .org / .info）と Kitaqnic（その他18種）の2社です。

覚えておくこと

はじめてでも、つまずかないように

この3つだけ頭に入れておけば、検索結果の読み方で迷うことはありません。

その1

TLDは選ばなくていい

名前だけ入れれば、対応する22のTLDすべてに問い合わせます。「.com がだめなら次は .net」と試し直す必要はありません。

その2

だめなときは代わりを出す

希望がすべて埋まっていたときだけ、似た候補を出します。しかも、その場で空きを確認できたものだけを表示します。

その3

分からないときは、そう書く

レジストリに繋がらなかったTLDは、空きとも使用中とも書きません。◯ / ✕ / ？ を記号と文字の両方で区別します。

見本

検索するとこう出ます

「my-shop」と入れたときの表示例です。空きが確認できた行にだけ、選択のボタンが付きます。
