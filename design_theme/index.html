トップページ デザインテーマ候補

ドメイン検索画面（トップ）だけを14案作りました。2・3・9〜14 はスタイルから作った案、4〜6 は既存レジストラのサイト（hover / hostinger / gandi）、1・7・8 は開発者向けクラウドのサイト（Porter / Koyeb / Fly.io）をベースにした案です。気に入った1案を選んでいただければ、その配色・書体・レイアウト規則を design system 化して、他の画面（申込・マイページ・会員登録）へ展開します。

19 candidates (14 + 5 derived from #4) · static html mockups · updated 2026-08-26

1ZINE

ジン・イエロー型（porter.run ベース）

クリーム地に蛍光イエロー、点線の枠、等幅のナビ、ピクセルのドット装飾。中央揃えの太い見出しの一部を色面でハイライトし、黒い矩形ボタンで締める同人誌的な紙面。

  • 想定: 技術系スタートアップのノリ
  • 写真・イラストを使わない
  • 最も目を引く
 2GRID

グリッド型（スイス・エディトリアル）

角丸ゼロ・影ゼロ。太い罫線と12カラムグリッドだけで構成し、「22」「¥98」を大きな数字として見せる。色は黒・白・青の3値のみ。

  • 想定: スタートアップ / 制作会社
  • 最も主張が強い
  • ブランド化しやすい
 3MINIMAL

ミニマル・ダークヒーロー型

墨緑の沈んだダークヒーローを2カラムで組み、左に細身の大見出しと検索窓、右に端末の全景（実際の検索結果）。以降は白地・極細罫線・大きな余白で、料金／方針4点／手順／FAQ／フッターまで通した1枚もの。

  • 想定: ブランドを立てたい個人・小規模事業者
  • 余白基調・低彩度
  • ページ量は最多
 4FRIENDLY

フレンドリー・グリーン型（hover.com ベース）

全面グリーンのヒーローを2カラムで組み、右にフラットイラスト（実際の検索結果を描いたCSS図形）。丸ゴシックの太い見出しと、白い矩形＋濃色ボタンの検索窓。直下に「いま安いTLD」の帯。

  • 想定: はじめてドメインを取る人
  • 親しみやすさ最優先
  • ティール系グリーン

候補4 から派生した5案 — 若葉マーク（初心者に優しい）方向

チームの評価が高かった候補4を土台に、緑の人格はそのままで「はじめての人を怖がらせない」表現だけを5通りに振ったものです。中身（22TLDの料金・セクション構成・固定文言）は候補4と完全に同じなので、見た目だけを比べられます。

全案に通した基本方針（参照元がある案は、その作法を優先）

  1. ヒーローの構図は案ごとに作り分け（左揃え・中央揃え・2カラムを混在させ、テンプレート化を避ける）
  2. ✨スパークルアイコンとピルバッジを削除
  3. 「アイコン＋短文の特徴3点」の横並びを削除し、実データ（全22TLDの初年度・更新料）に置き換え
  4. 意味を運ばないスローガン（「個人でも法人でも。選べるTLDラインナップ」等）を削除
  5. 角丸と影をテーマごとに1種類へ統一
  6. 見出しに書体の個性を持たせる（明朝 / 等幅 / Archivo など）

テストが固定している文言（ドメイン検索 / 取得したいドメイン名 / 検索する / ヒント文 / AuthContext: 未認証）は14案とも維持しています。
